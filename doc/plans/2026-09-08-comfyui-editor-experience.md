# ComfyUI 工作流打开与编辑体验

## 范围与状态

修复打开空白和标签/画布不一致，完善加载、失败和重试反馈；代码与离线回归完成，桌面运行验收待完成。主文档：[ComfyUI 集成说明](../ComfyUI工作流集成说明.md)。

- 复用标签必须实际载入其当前草稿图，不把更新标签状态当成载图成功。
- 启动时等待画布、前端初始化与历史恢复；载入完成检查画布节点，空布局回落 API 自动排布。
- 通过带请求 ID 的结果回执区分开窗与载入完成；主界面显示正在载入、错误与重试。
- 请求串行，重复点击合并；未完成请求不会被后续请求静默覆盖。
- 连接检查失败保留已有编辑窗口，避免临时离线导致未保存草稿丢失。
- 本地和远程 HTTP(S) 服务共用自动载入、结果回执和保存回写链路；桥接和工作流正文仅对配置地址同源的顶层页面生效，禁止跨来源导航，不新增 Tauri IPC 权限。

## 验收与回滚

- 已通过：5 个测试文件、54 项用例，覆盖真实桥接脚本的启动等待、多标签草稿切换、空布局恢复、请求串行、视口居中、保存身份，以及编辑服务和面板重试交互。
- 已通过：前端与测试 TypeScript 检查、改动文件 ESLint、桥接 JS 语法检查、严格 UTF-8 与差异检查。
- Rust：`cargo check --lib` 与 `cargo check --tests --lib` 通过；`cargo test comfyui::tests --lib` 在 ONNX 链接阶段被本机 MSVC C++ 运行库符号缺失阻断（LNK1120），原生测试未执行。未为此调整依赖或工具链。
- 待验收：重新编译桌面应用后的首次打开、A/B/A 标签切换、实际工作流节点与明暗主题显示；未启动应用或 ComfyUI，也未执行媒体生成。插件或前端内部加载长期不返回时会报告超时，但不会擅自取消第三方加载或丢弃草稿。

不更改 ComfyUI 安装、工作流数据或运行服务，不新增依赖或通用 IPC 权限。仅撤销本批桥接、窗口打开、界面状态与测试文档差异即可回滚；保留同文件的其他任务改动。

### 2026-09-17 远程编辑支持

- 已支持配置的远程 HTTP(S) 服务自动载入和保存回写，复用现有草稿标签与载入回执。来源绑定包含协议、主机和端口；工作流正文与桥接仅在同源顶层页面执行，跨来源导航被拒绝，宿主动作执行前再次校验当前页面。
- 未新增依赖，未更改 Tauri capability 或安全配置；本地连接预检保留，远程沿用 WebView 连接及载入超时反馈。跨来源登录跳转不受支持；另存新工作流仍需手动选择服务器。
- 已通过：4 个 Vitest 文件、59 项测试（包含远程 HTTP/HTTPS 载入和保存、错误来源、子 frame 拦截）；测试类型检查、定向 ESLint、桥接 JS 语法、严格 UTF-8 和差异检查。
- 已通过：`cargo check --lib`、`cargo test comfyui::tests --lib`（13 项）。此前记录的原生链接阻断未在本次复现。
- 尚未连接真实远程 ComfyUI 进行桌面验收；需重新启动 Tauri 开发进程或重新打包应用。回滚撤销本节对应的原生窗口、桥接、测试和文档改动，恢复仅本地自动载入，不迁移用户数据。
