# 关键发现

- AST 扫描发现 28 个组件文件中有 71 处原生 select，其中 69 处为可见业务控件。
- 共享 Select 已提供 UI Kit 样式、分组、禁用选项、固定 Portal、视口定位和限高滚动。
- 样式演示有一套独立的自定义 Select 实现，应改为直接复用共享组件。
- 角色弹窗使用 autoFocus；插件工具表单使用 required；MCP 设置使用 aria-describedby；剪辑转场传递连续编辑事件；导演节点回调显式接收 HTMLSelectElement 事件。这些都不能用机械标签替换丢弃。
- 现有组件测试可能依赖原生标签或 ChangeEvent，需要随对应业务迁移调整，保留参数语义断言。
- 根目录 planning 文件属于既有插件任务，不覆盖；本次计划独立放在 doc/plans 中。
- 设置面板使用 z-index 10000，原共享 Select 固定层级 300 不够；菜单层级改为至少高于所属祖先层级，所有本次迁移显式使用 body Portal。
- 镜头设置与视频参数弹窗存在 document 捕获的外部点击监听，已将 Select Portal 菜单纳入内部交互。
- 共享控件接收声明式 option/optgroup，统一解析成 UI Kit 菜单与隐藏原生表单选项，保留动态片段和原有标签。
- 节点弹窗和图层合成器使用 window 捕获快捷键，比下拉挂载后注册的监听更早；增加宿主侧避让，防止 Escape 误关父弹窗和方向键误移图层。
- 控件聚焦时隔离画布删除、撤销和字母快捷键；视频转场通过选择回调包裹编辑开始/结束，保持一次离散选择的历史边界。
- 隔离浏览器实测：菜单为 body 子元素，z-index 10001，高度 320，视口内且命中测试可达；明暗主题显示正确。空值提交被阻止，选择字符串 0 后提交成功，Escape 未触发父层处理。

- 用户反馈的中文竖排来自 Portal 菜单被赋予触发器宽度；改为 max-content 并设置视口最大宽度。浏览器实测：70px 与 450px 触发器均展开为 86px 内容菜单，中文名称单行；1280px 视口中超长内容菜单为 1264px，两侧各留 8px，无横向溢出。
