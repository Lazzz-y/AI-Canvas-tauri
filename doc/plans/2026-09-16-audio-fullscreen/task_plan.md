# 音频节点全屏播放器

## 目标与状态

类型：产品能力。用户已确认本批文件范围；实现、自动检查与浏览器验收已完成，桌面协议验收边界见下文。

- 双击有音频的生成/源音频节点，打开占满应用窗口的播放器；复用图片预览的 Portal 全屏层，Escape 和关闭按钮退出。
- 提供播放/暂停、可拖动进度、当前时间/总时长、音量与静音。
- 上一曲/下一曲按当前项目节点 `displayId` 数值升序；缺少编号的排后，跳过空音频和角色库收纳节点，首尾不循环。播放结束顺序进入下一曲，最后一曲结束停止。
- 显示真实 Web Audio 实时频率曲线，采用对数频率轴与 dB 刻度，参考用户图片的图表结构。不得用随机数据模拟频谱。
- 打开时暂停节点内播放并接续当前位置，关闭时停止全屏播放；切歌释放旧媒体，项目切换、当前节点删除或来源改变时正确清理。

## 验收与风险

- 数字编号例如 2、10、30 按数值切歌，不按文本或数组顺序；不写节点选择或历史。
- 拖动与音量键盘操作不触发背景画布快捷键；双击不能导致两个播放器同时出声。
- 频谱来自实际播放信号；播放失败可见，分析不可用不能破坏基础播放。
- 远程音频跨域授权、Tauri asset 协议与 Web Audio 的实际兼容性需要验收，不能由静态检查推定。跨域分析失败应明确显示频谱不可用并保留可用的基础播放，不能放宽安全配置。
- 明暗主题沿用现有 token；长标题和小窗口仍能操作。
- 回滚只撤销以上清单中本任务差异；不删除用户媒体、不影响项目数据。
