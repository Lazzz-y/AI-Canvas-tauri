# 图片调用协议选择实施计划

## 范围与状态

- 状态：已实现，待桌面界面和真实中转站调用验收。
- 自定义连接的每个图片模型通过该模型右侧的调用协议设置，直接选择 GPT-Image 中转站 JSON、OpenAI 官方 Images、Google 原生图片、xAI 原生图片，或高级自定义 JSON。
- 图片与文本模型的高级自定义入口只显示 JSON 编辑，不显示复杂表单；视频、音频和工作流保留原编辑方式。文本模型未设置模型级协议时继续使用连接级对话协议。
- 文本模型可单独选择 OpenAI Chat、Anthropic Messages 或 Google Gemini generateContent；后两项复用已存在的对话 API 适配器，覆盖文本节点非流式调用与助手流式调用，并保留高级自定义 JSON。

## 关键边界

- 中转站 JSON 预设按已提供合同提交 `/images/generations`，用 `images` 数组携带本次存在的参考图，从 `data.*.url` 读取结果。它只适用于接受该合同的中转站，不按模型名称自动套用。
- OpenAI 官方 Images 预设在无参考图时走生成接口；有参考图时复用现有标准 multipart 编辑请求。Google、xAI 原生图片选项目前只覆盖文生图；带参考图的请求由既有协议校验拦截，不静默忽略。
- 旧模型级协议和旧 `openai-image` 预设不改写。若用户曾保存短暂提供的连接级图片默认值，打开该连接时会将其复制到未单独配置的已选图片模型；再次保存后只保留模型级配置，不继续隐式继承。
- 自定义 JSON 仍走原有协议校验、同源路径限制、鉴权注入、预览和试跑链路，不引入新传输或新依赖。
- Anthropic 和 Gemini 文本预设是原生对话适配器，不编译成声明式 JSON；它们复用已有的消息、工具、图片输入与流式事件转换。连接级对话协议继续作为未单独设置模型的默认值。

## 验证与缺口

- 离线验证：协议编辑器、旧图片默认值迁移、图片请求体与参考图传输、文本节点、助手流式适配器、连接协议和配置 Store 共八个测试文件、208 项通过。覆盖模型级 Anthropic/Gemini 选择覆盖连接默认值、旧参考图模式不覆盖中转站 JSON，以及各模型协议互不影响。拉取最新 `origin/master` 后，类型检查、改动文件定向 ESLint、Vite 临时目录构建、严格 UTF-8 编码扫描与差异检查通过。
- 桌面暗色与浅色主题、真实中转站返回、真实官方接口和付费生成尚未验收。中转站如果要求不同的鉴权、字段或响应路径，应使用自定义 JSON。

## 回滚

撤销本计划对应的预设、模型设置界面与兼容读取即可；旧模型级配置保留，不需要数据库迁移。
