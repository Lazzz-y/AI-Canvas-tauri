# AI Canvas 新用户教程文案纲要

> 配套：[教程制作方案](plans/2026-09-16-新用户教程制作方案.md) · [使用说明书](../site/manual.html)
>
> 面向新用户；核对日期 2026-09-16，当前源码版本 0.9.10。本文提供六集结构、关键口播、首集试录稿与案例提示词。均为拟录内容，尚未录屏、合成旁白或生成案例素材。

## 全片统一写法

一句话主张：**把图片、视频和声音放到同一张画布上，按步骤做出你的第一支短片。**

每集采用“先看结果 → 解释用途 → 实际操作 → 检查结果 → 一项练习”的顺序。口播直接说操作，技术名词在首次出现时解释。屏幕指令、剪辑备注和按钮名称提示不送入语音合成；只有标为“口播”的内容用于配音。

片头推荐文案：

> 这支短片，从三张图片开始。接下来，我们用 AI Canvas，把图片变成镜头，加上声音，再导出一支完整的视频。即使你第一次接触节点画布，也可以跟着做。

使用此开场前必须先完成真实案例。样片尚未完成时，将“这支短片”改成“这套教程的目标是一支短片”，不展示概念图冒充成片。

## 第 01 集：先认识画布，我们要做出什么

目标：认识项目、节点、连线和输出；不在这一集讲解接口协议。预计 4–5 分钟，包含鼠标演示、停顿和成片播放。

| 段落 | 屏幕内容与操作 | 口播要点 | 完成标志 |
|---|---|---|---|
| 01 开场 | 全屏播放案例，再回到对应画布 | 今天做什么，最终交付什么 | 观众看见目标作品 |
| 02 画布 | 从画布全景缩放到一个源图节点 | 节点就是一张素材卡片或一项生成任务 | 图像、视频、音频节点能区分 |
| 03 生成关系 | 指向图片与视频的引用或连线 | 连线帮助下游使用上游素材；仍需检查模型支持 | 理解引用不等于生成 |
| 04 界面入口 | 指示项目、添加节点、设置、输出历史 | 第一阶段只记住四个位置 | 可跟随鼠标找到入口 |
| 05 路线 | 展示三张图、三段视频、配音和成片 | 下一集先完成一张图，逐集扩展 | 学习顺序清晰 |
| 06 练习 | 回到新项目起始状态 | 打开软件并找到设置、添加节点入口 | 为第二集做好准备 |

### 第一集试录稿

以下六段分别合成，段间留约 0.5–1 秒空白；时间以试听与真实操作为准。整集时长由口播加屏幕演示组成，不要求把四分钟内容挤进连续旁白。

**E01-S01 · 开场口播**

> 先看一下我们要完成的效果。晨光照进房间，桌上是一杯刚做好的咖啡。镜头慢慢靠近，最后停在一个干净的收尾画面。这支短片用到的图片、视频和声音，都可以放在同一个项目里整理。这套教程，我们就从一张空白画布开始，一步一步把它做出来。

屏幕：播放实际成片 15–20 秒，此时暂停教程旁白；成片结束后切回完整画布，展示素材与结果。成片必须在录制前实际制作。

**E01-S02 · 软件定位口播**

> AI Canvas 用一张画布，组织你的创作过程。你可以把参考图片放进来，写好提示词，选择已经配置的模型，再生成新的图片或视频。需要声音时，也可以导入已有音频，或者选择合适的语音模型。模型连接和生成费用由你使用的平台决定，我们下一集会实际配置一个连接。

屏幕：缓慢指向图像、视频、音频三类节点；每个节点停留 2 秒，不同时打开多个面板。

**E01-S03 · 节点口播**

> 画布上的这些卡片，叫作节点。你可以先把它理解成一张素材卡，或者一项待完成的任务。源文件节点用来放已有素材，生成节点用来输入要求、选择模型和查看结果。空节点只是准备好了一个位置，真正的图片和视频，要等生成完成后才能看到。

屏幕：依次展示源图片、空生成节点和有结果的生成节点。演示素材可以预先准备，但字幕注明“已完成的示例项目”。

**E01-S04 · 引用与连线口播**

> 如果希望视频接着这张图片来做，就要把图片提供给视频节点。你会看到引用或连线这样的操作，它们用来说明这一步使用哪份素材。不过，接上图片以后，还要检查视频模型是否支持这种输入。我们会在图生视频那一集，完整做一次。现在先记住，素材要选对，结果也要实际播放检查。

屏幕：高亮一组图片与视频关系，不提交生成。短暂停留在参考图缩略图，说明引用确实存在。

**E01-S05 · 四个入口口播**

> 第一次打开，不用把所有按钮都学会。先记住四个位置：项目入口，用来整理不同作品；添加节点，用来放入新的任务；设置，用来连接你的模型服务；输出历史，用来找回和比较生成结果。移动和缩放画布的方式，可以在常规设置里查看。跟着教程时，先确认自己的交互模式。

屏幕：逐个高亮四个实际入口；在常规设置展示当前交互模式，不把某一模式的按键说成全部用户通用。

**E01-S06 · 路线与结尾口播**

> 后面的操作分成五步。先连接模型，生成第一张图；再补齐三个镜头需要的画面；接着把它们变成短视频；然后加入配音，调整顺序；最后导出成片，备份项目。你已经有自己的声音，也可以直接拿来做配音。下一集，我们先把模型接好，完成第一张真正能预览的图片。

屏幕：按顺序亮起五步清单。结尾任务卡：“找到设置和添加节点入口；准备可用的模型账户。”

## 第 02 集：接好模型，生成第一张图

目标：完成一次可验证的出图。预计 7–9 分钟。

| 顺序 | 实际操作 | 关键口播 | 画面提示 / 检查 |
|---|---|---|---|
| 1 | 打开设置 → API Key | “连接决定向哪个服务发请求；模型决定具体使用哪项能力。” | 录制一个实际可用的内置厂商，不同时演示多家 |
| 2 | 填入该厂商要求的信息，启用图像与视频模型 | “密钥使用你自己的账户信息。模型勾选后，还要保存连接。” | 密钥输入全过程遮挡；不展示账户余额 |
| 3 | 保存并返回节点核对模型列表 | “能在节点里选到，才完成这一部分配置。” | 显示保存操作和实际模型名称 |
| 4 | 新建案例项目，添加生成图像节点 | “这张节点负责第一个镜头的画面。” | 节点命名为“镜头01-晨光咖啡桌” |
| 5 | 输入附录提示词，选择比例和模型 | “第一次先固定主体、场景和构图，只生成一张。” | 选模型实际支持的 16:9 比例；先不做批量 |
| 6 | 点击生成，展示提交与等待 | “现在才是实际调用模型的步骤，可能产生服务费用。” | 等待压缩时字幕标明；不反复点击生成 |
| 7 | 预览真实图片，查看输出历史 | “图片能打开，结果也能在历史里找到，这一步才算完成。” | 放大结果，指出杯子、光线和构图是否符合 |

转场口播：

> 第一张图已经有了。下一集，我们继续沿用这只杯子和这张桌子，补齐另外两个镜头，让短片的画面看起来属于同一个场景。

本集故障支线只讲三项：模型没出现先查是否启用和保存；鉴权失败先核对连接；有任务 ID 却没有结果先查原任务。自定义协议问题跳转选学专题 C，不在主课中展开完整 JSON。

练习：使用相同流程生成自己的一张图，写下实际使用的模型名称。

## 第 03 集：用参考图补齐三个镜头

目标：三张画面足够一致，可以进入视频制作。预计 5–6 分钟。

1. 展示三镜头草图：全景、近景、收尾，只改构图与镜头距离。
2. 打开项目设置，说明画风文字、风格母图和提示词后缀分别影响什么。首课案例只固定必要的画风与比例，其他留默认。
3. 添加第二、第三个图像节点；使用支持参考图的模型，从画布引用第一张已确认的图片。
4. 分别输入附录镜头 02、03 提示词，生成并比较；任何不一致先针对一个问题调整。
5. 给最终选用的结果清楚命名，使用输出历史比较候选；练习按 Tab 查看资产侧栏。

关键口播：

> 我们希望保留的是同一只杯子、同一张桌子和同一种光线。第二张图主要改变景别，第三张图负责收尾。参考图能帮助模型理解这些要求，但生成以后仍然要看一遍，确认没有换杯子、变环境，或者多出不需要的东西。

屏幕文字：主体一致／色调一致／比例一致。不要把“已引用”标为“一致性已保证”。

练习：保留三张确定使用的图，各用一句话说明镜头用途。

## 第 04 集：把静态画面变成短镜头

目标：三段真实视频可以播放。预计 6–8 分钟。

1. 先播放镜头 01 成品，再回到它的参考图片。
2. 新增生成视频节点，选择已配置且支持图生视频的模型。
3. 按该模型提供的参考图或首帧入口添加正确图片，确认缩略图；提示词只增加需要的动作和运镜。
4. 从界面实际选项中选择时长、尺寸和比例。先生成一个镜头，确认后再做其余两段。
5. 查看进度与结果；若等待中断，先核对原任务，支持恢复的路径使用继续查询。
6. 播放三个镜头，检查主体变形、闪动、动作幅度和首尾是否能剪接。

关键口播：

> 图片已经把场景说明白了。到了视频这一步，重点写接下来发生什么：热气缓慢上升，镜头轻轻靠近，杯子和桌面保持稳定。先给一个简单、能看清的动作，生成以后实际播放，再决定要不要加复杂变化。

完成标志：有三段可播放素材；时长和动作不合适时在进入剪辑前处理。不要用进度达到 100% 代替结果回填。

练习：给每段视频写一个动作要求，生成后比较实际执行情况。

## 第 05 集：导入旁白，剪成完整短片

目标：完成一条可连续播放的时间轴。预计 8–9 分钟。

| 顺序 | 实际操作 | 关键口播 | 验收画面 |
|---|---|---|---|
| 1 | 导入已经准备好的案例配音到音频节点并试听 | “已有配音可以直接使用，不需要为了剪辑再生成一次。” | 播放案例旁白，教程讲解暂停 |
| 2 | 多选视频素材，右键编辑视频 | “先有至少一个视频素材，再从右键进入剪辑窗口。” | 展示三个镜头进入时间轴 |
| 3 | 调整镜头顺序与长度 | “先让三个镜头能顺着看完，再做装饰。” | 从全景到近景再到收尾 |
| 4 | 通过添加素材导入案例配音，放到音频轨 | “旁白是一条独立音轨，可以单独移动和裁切。” | 声音起点与第一个画面一致 |
| 5 | 裁切片段、必要时分割、添加收尾文字 | “文字放在留白位置，先确保能看清，不急着加复杂转场。” | 标题不遮挡杯子；文字持续时间正确 |
| 6 | 完整播放并修正 | “现在只看作品，听声音有没有被切断，画面有没有突然跳走。” | 无讲解地播放完整时间轴 |

旁白段建议：作品头 1 秒留环境停顿，配音覆盖主要镜头，最后约 1–2 秒留给收尾画面。具体以实际音频长度调整，不靠拉快配音硬塞。

全屏播放器演示放在选学或本集补充片段：仅包含后续更新的构建可双击音频展示区打开。主课导入配音与剪辑流程不依赖该入口。

练习：完成一条 15–20 秒左右时间轴，保存剪辑工程并全程播放一次。

## 第 06 集：导出、验片和备份

目标：拿到 MP4 和可迁移项目包。预计 4–6 分钟。

1. 在剪辑窗口选择导出到本地，检查比例、尺寸和帧率；按当前机器提供的导出能力选择。
2. 说明加入文字、叠加或混合素材可能走合成重编码，不承诺全程无损或固定耗时。
3. 导出后用独立播放器打开文件，从头看到尾；确认音画、文字、结尾与时长。
4. 回到桌面项目库，从项目菜单导出 `.aicanvas` 项目包；说明视频成片和项目备份用途不同。
5. 演示导入项目包生成独立副本，并抽查主要素材；换电脑还需重新配置模型凭据与外部服务。

结尾口播：

> 到这里，你已经走完了一次完整流程：从模型连接开始，生成图片，把画面变成镜头，再加入配音，导出成片。以后换成产品展示、旅行片段或自己的故事，都可以沿用这条顺序。先用少量素材完成一支短片，再逐步增加镜头和功能。

本集练习：独立播放导出文件，并保留一个已抽查的项目包。后续引导指向“角色声音复用”和“AI 助手整理项目”，不强制观众继续安装工具。

## 选学专题口播纲要

| 专题 | 开场问题 | 操作骨架 | 结尾交付 |
|---|---|---|---|
| A 角色声音复用 | “配音样本准备好了，怎样每次都能找到它？” | 上传／绑定声音 → 展开列表 → 试听 → 设主音色 → 音频节点引用 → 新台词 | 一条使用指定样本的可试听结果 |
| B 语音参数 | “台词、参考录音和声音描述，分别放在哪里？” | 对比 AuK 文生与参考模式 → Qwen3 克隆与抽卡 → 固定参数 → 一句测试 | 一个已试听的参数组合；标注构建和依赖 |
| C 自定义接口 | “平台有接口，为什么模型仍不能用？” | 连接与模型 → 文档导入或手动协议 → 请求预览 → 响应路径 → 一次试跑 | 可保存复用的连接配置 |
| D 工作流 | “已有 ComfyUI 工作流，怎样接到画布？” | 选服务器 → 绑定工作流 → 输入映射 → 小任务 → 进度与恢复 | 一条能回填真实素材的工作流 |
| E AI 助手 | “可以让助手先帮我检查缺什么吗？” | 选文本模型 → 引用素材 → 规划分析 → 协作确认一项写入 | 任务结果与画布变化一一对应 |
| F 剧本分镜 | “镜头多起来以后，怎样保持顺序？” | 本集剧本 → 分镜表 → 检查镜头 → 准备素材 → 推送时间轴 | 一张有顺序和素材的分镜表 |
| G MCP 与插件 | “怎样让外部工具参与这个项目？” | 安装或连接前提 → 指定项目 → 先读取 → 明确任务 → 核对结果 | 一个范围明确、结果可见的任务 |

角色声音专题关键句：

> 这里保存的是声音样本，下面写的是这一次的新台词。先试听，确定选中了想要的声音，再开始生成。如果后来换了角色的主音色，已有引用不会自动替换，旧节点里也要检查一次。

Qwen3 专题关键句：

> 克隆、声音抽卡和参考音频抽卡，是三种不同的工作流。列表里的名字方便区分用途，实际声音是否合适，要以生成后试听为准。参数里显示的长度上限也不是精确秒数，太低可能让台词说不完整。

Agent 专题关键句：

> 先选规划，让助手分析现有素材。需要它修改时，再使用协作模式检查确认项。自主模式和 MCP 可以直接执行写入与生成，所以任务范围和目标模型要在执行前说清楚。

## 附录 A：三镜头案例提示词

下面是可供录制前试跑的文案，尚未验证实际模型输出。后两张图应显式引用第一张已确认图片；按钮和参数按录制所用模型填写，不把提示词中的文字当作参数设置。

**镜头 01 · 图像**

```text
清晨的室内咖啡桌，一只没有文字和图案的白色陶瓷杯放在浅木色桌面上，杯中是刚做好的黑咖啡。左侧窗户透入柔和晨光，背景简洁，杯子位于画面左侧三分之一，右侧保留干净的空间。中景，真实摄影质感，安静自然。
```

**镜头 02 · 图像，引用镜头 01**

```text
沿用参考图片中的白色陶瓷杯、浅木色桌面和左侧晨光。改为杯口与杯身的近景，黑咖啡表面有柔和反光，少量细薄热气上升，背景轻微虚化。保持杯子的形状、颜色和场景陈设一致，真实摄影质感。
```

**镜头 03 · 图像，引用镜头 01**

```text
沿用参考图片中的白色陶瓷杯和浅木色桌面。以稍低的侧面视角拍摄，杯子仍在画面左侧，右侧留出简洁的明亮空间，用于后期添加文字。保持原来的柔和晨光与安静氛围，真实摄影质感，画面内不生成文字。
```

**视频动作提示，按镜头分别使用**

```text
镜头01：镜头缓慢向咖啡杯靠近，晨光保持柔和稳定，热气轻轻上升，杯子和桌面静止。
镜头02：固定机位拍摄杯口，细薄热气缓慢上升并自然散开，咖啡液面只有轻微变化，杯子形状保持稳定。
镜头03：固定机位，柔和热气轻轻散开，保持白色杯子和右侧留白稳定，安静收尾。
```

若当前视频模型提供独立负面提示词栏，可按其能力填写“不出现新物体，不出现明显形变，不出现额外文字”；没有该栏时不虚构控件。生成结果仍需实际检查。

## 附录 B：案例旁白与收尾文字

**案例旁白，单独复制给已准备好的克隆音色：**

```text
早晨，先给自己一杯咖啡的时间。
让热气慢慢升起，让思绪安静下来。
今天，从这一刻开始。
```

三句建议分别合成后试听，目标覆盖约 12–16 秒，实际长短随音色与语速变化；留给开头和收尾画面约 2–4 秒。若太长先精简文字，不承诺用某个参数精确控制秒数。

**配音风格：**自然、温和、平静的中文讲述；句间稍停顿，句尾自然收住；保留现有克隆音色，不额外设计新音色。

**收尾文字：**“今天，从这一刻开始。”由剪辑器后期添加，避免依赖图像模型生成准确中文字。
