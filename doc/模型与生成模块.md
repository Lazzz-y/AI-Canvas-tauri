# 模型与生成

负责模型目录、厂商协议、图片/视频/音频生成及工作流适配。生成成功、取消、产物保存是需要分别处理的状态。

## 主要入口

| 入口 | 职责 |
|---|---|
| [generationRuntime.ts](../src/services/ai/generationRuntime.ts) | 对话媒体生成：解析模型、分派生成并保存产物 |
| [mediaProviderRegistry.ts](../src/services/ai/mediaProviderRegistry.ts) | 参考媒体与 Provider 能力分派 |
| [modelProtocol.ts](../src/services/ai/modelProtocol.ts) / [providers](../src/services/ai/providers/) | 声明式模型协议与厂商适配 |
| [media.ts](../src/types/media.ts) | 媒体生成意图、结果与持久化状态合同 |
| [comfyWorkflowService.ts](../src/services/comfyWorkflowService.ts) / [comfyProgress.ts](../src/services/comfyProgress.ts) | ComfyUI 输入注入、可选分支清理、执行与实时节点进度 |
| [workflowApi](../src/services/workflowApi/) / [workflowExecutionService.ts](../src/services/workflowExecutionService.ts) | 工作流 API 合同与执行；与 RunningHub 共用工作流绑定和云产物保存 |

## 关键边界

- 对话生成走统一入口；节点生成沿用节点/生成服务，不能声称所有入口已统一迁移。
- 工作流与厂商模型 API 使用各自适配协议；鉴权、上传、轮询和解析不散落在节点组件中。
- 参考图按已声明协议传输：标准 `edits-multipart` 直接读取原图，不先上传第三方图床；高级自定义协议优先保留自身路径、字段和响应/轮询映射，multipart 的 `$file` 图片引用转换为受限 data URL 后编码为文件。`$file` 可接收数组并按原字段名提交多个文件；请求预览逐文件脱敏。APIMart 继续使用自身上传服务，未确认支持 multipart 的厂商不自动切换或失败后重提生成。
- CCC 旧 Provider 节点与缺少参考图模式的旧通用模型，按已声明的厂商目录补全传输模式；显式模型配置优先，未知厂商不按模型名称猜协议。multipart 和 data URL 请求中的提示词参考图优先使用本地素材，不复用生成结果的远程 sourceUrl。自定义协议仍按自身字段执行；纯文生图请求体缺少参考图映射时会在本地拦截，这与上游 HTTP 502 属于不同阶段。
- 标准 GPT Image multipart 对超过 4 MiB 的 8 位不透明 RGB 静态 PNG，逐张准备 95% 质量 JPEG 临时上传副本，保留像素尺寸，节省不足 20% 时仍用原图；透明、动画、其他格式、超过 2400 万像素及无法解码的图片保持原字节。本地文件不变，APIMart 与高级自定义协议不走这项转换。网络提交失败或 HTTP 504 显示实际模型、参考图数量、提交体积及等待时间；原生错误只保留类别与系统错误码，不泄露 URL 参数。结果不确定时不自动重提生成。
- 自定义接口文档导入支持带引号的 cURL `-F` / `--form` 图片文件参数及 `--form-string` 文本参数，保存识别出的参考图模式；单个 `image` 映射第一张，`image[]`、复数字段或同名重复文件字段映射全部参考图。示例文件路径不读取、不保留；未知文件字段或无法解析的表单语法明确拒绝并提示手动配置。验证入口：`modelProtocolImport.test.ts`、`modelProtocol.test.ts`、`modelRequestTransport.test.ts`。
- 取消需要贯穿提交、轮询和回填。模型已生成但保存失败时，应报告保存状态，不能把再次生成当作保存重试。
- API Key 由凭据服务管理，运行记录不携带密钥。工具审批归[Agent Policy](./对话助手-Agent能力实施方案.md)，不由 Provider 改写。

## 配置与运行状态

用户配置见[说明书：自定义接口](../site/manual.html#connection)和[本地与云端工作流](../site/manual.html#comfy)。厂商模型、RunningHub 工作流和通用工作流 API 的 Key、参数与恢复状态分别处理，不能互相套用。

模型选择器的工作流分组默认收起，无可用条目时整体隐藏。ComfyUI 工作流按实际绑定地址探测 `/system_stats`，仅展示在线服务对应的条目；未绑定或服务器已删除时沿用默认地址回落。打开菜单立即检测，打开期间每 10 秒刷新，关闭后取消检测；RunningHub 与工作流 API 不受 ComfyUI 在线状态影响，已有节点选择不因暂时离线被清空。验证入口：`modelSelectorWorkflows.test.tsx`、`comfyServerBinding.test.ts`。

ComfyUI 提交前只绕过能够确认的空可选媒体分支；必填或未知结构交由原工作流校验。视频节点未设置秒数或旧帧数时使用 5 秒默认值，旧帧数兼容换算。实时百分比属于当前执行节点，任务完成仍需查询输出并保存成功；具体注入和回退规则见[ComfyUI 集成](./ComfyUI工作流集成说明.md)。

## 验证与资料

- 工作流 API：通用独立连接，可添加多个平台及命名工作流，自由配置提交/查询路径、鉴权、参数与结果映射。复用 modelProtocol 编辑器和执行器，支持同步/异步 JSON 媒体 URL 输出、图片/视频/音频参数控件；H3 为可编辑模板，旧配置保持兼容。本地素材复用上传服务，整数组和完整编号映射均可发送多图；任务恢复绑定提交时的协议，未知提交不自动重提。前端类型与定向 ESLint 通过，按用户要求未运行本阶段测试及真实服务调用。配置示例、恢复和回滚见[工作流 API 计划](./plans/2026-09-08-autodl-workflow-api/task_plan.md)；源码：[通用定义](../src/services/workflowApi/workflowApiDefinition.ts)、[执行与恢复](../src/services/workflowApi/workflowApiAdapter.ts)，既有测试入口：[配置与分享](../tests/services/workflowApiConfig.test.ts)、[设置入口](../tests/components/providerWorkflowSection.test.tsx)。
- RunningHub 云工作流与 AI 应用：支持定义导入、类型化参数、图片/视频/音频官方上传、节点与对话调用、多产物保存及任务恢复。旧本地工作流保持 ComfyUI 语义；工作流与标准模型使用各自适配器。状态、验收缺口、后续模型扩展与回滚见[RunningHub 平台计划](./plans/2026-09-08-runninghub-platform.md)；测试入口：[定义导入](../tests/services/runninghubWorkflowService.test.ts)、[任务生命周期](../tests/services/runninghubWorkflow.test.ts)。
- RunningHub 标准模型：347 个媒体操作与 7 个旧图片选择共用 manifest、专属参数和媒体 Registry；已有启用选择保留。标准模型用 v2/query 恢复，批量未知提交不自动重提，标准停止等待与工作流取消分开；33 个专项/弃用操作及真实服务验收缺口见上述平台计划。测试入口：[模型合同](../tests/services/runninghubModelManifest.test.ts)、[标准执行与恢复](../tests/services/runninghubMedia.test.ts)。
- APIMart Omni：内置目录以 `gemini-omni-1.1-flash`、`gemini-omni-1.1-flash-ext`、`gemini-omni-flash-preview` 替换旧 `Omni-Flash-Ext`；旧画布 ID 兼容到新 Ext，旧目录选择在设置页迁移，未选择的模型不自动启用。Google 直连目录独立保留。
- 能力及请求合同集中在 [apimartVideoModels.ts](../src/services/ai/apimartVideoModels.ts)：Flash/Preview 不提交时长；Ext 仅允许 4/6/8/10 秒，引用视频时省略时长。Flash 图片含首尾帧合计最多 10 张，Ext 参考图仅 1 或 3 张，Preview 最多 16 张；均最多 1 段参考视频、不接受参考音频。Flash 视频最长 10 秒，Preview 视频 1–24 秒，由现有媒体元数据校验拦截。素材上传、取消与轮询复用 APIMart Adapter。
- Omni 本次接入现有文生、图生、视频参考和 Flash 首尾帧入口；按任务 ID 续写（`extend_from_task_id`）尚无独立产品入口。定向回归 6 个文件、102 项测试通过；未执行真实付费生成或桌面视觉验收。回滚时撤销本批代码；已迁移的模型选择可在设置中重新勾选，不修改画布历史。
- 接口依据：[Flash](https://docs.apimart.ai/cn/api-reference/videos/gemini-omni-1.1-flash/generation)、[Ext](https://docs.apimart.ai/cn/api-reference/videos/omni-flash-ext/generation)、[Preview](https://docs.apimart.ai/cn/api-reference/videos/gemini-omni-flash-preview/generation)；测试入口：[APIMart 生成](../tests/services/apimartGen.test.ts)、[模型目录](../tests/components/defaultModels.test.ts)。
- CCC API 内置图片目录包含 `gpt-image-2.5-flare`（速度优先）与 `gpt-image-2.5-sunburst`（质量优先）。两者无参考图时走 `/images/generations`，有参考图时走 `/images/edits` multipart，并沿用标准图片响应解析；真实 Key、透明背景输出和付费生成仍需桌面手工验收。测试入口：[CCC API 模型目录](../tests/services/providerCatalogService.test.ts)、[标准图片请求](../tests/services/modelRequestTransport.test.ts)。
